# hl的AI个人工作台

个人效率工具 - 计划、学习、记账一体化

## 功能模块

- 📅 每日计划
- 🍎 饮食记录
- 📚 系统分析师备考
- 🤖 AI课程学习
- 💰 记账存钱
- 🎨 配色调整

## 特性

- ✅ PWA支持，可添加到手机主屏幕
- ✅ 数据本地存储，隐私安全
- ✅ 支持导出/导入备份
- ✅ 离线可用
- ✅ 响应式设计，手机电脑都能用

## 使用方法

1. 浏览器打开 `index.html`
2. 手机端可添加到主屏幕作为APP使用
3. 所有数据自动保存在浏览器本地

## 技术栈

- 纯HTML/CSS/JavaScript
- PWA (Progressive Web App)
- LocalStorage数据持久化
